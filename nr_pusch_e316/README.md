# nr_pusch_e316 — WirelessNN PUSCH на ANTSDR E316

Приёмник (и передатчик для проверки) сигнала 5G NR PUSCH из симулятора
[WirelessNN](../../WirelessNN) для платы ANTSDR E316 (AD9361, прошивка Pluto v0.39).
Сигнал — ровно тот, что моделирует WirelessNN: 68 PRB × 30 кГц (816 поднесущих, 24.5 МГц),
FFT 1024, 30.72 MSps, 14 OFDM-символов, DMRS Type-1 в символах 2 и 11, MCS по
пресетам WirelessNN (QPSK / 16QAM / 64QAM), LDPC. Оценка канала, эквалайзер и
декодер — классы WirelessNN (`PuschRx`: `ls_lin`, `ls_soft_window`, `lmmse` …).

```
кадр (30.72 MSps):  [ слот 14×(89+1024) = 15582 ][ пауза 2466 нулей ]  = 18048 отсчётов (587 мкс)
```

Пауза даёт приёмнику оценку шума и выравнивает кадр под DMA (кратно 16).

## Запуск

Всё выполняется в виртуальном окружении WirelessNN (Sionna 2.x + PyTorch), из корня репозитория:

```bash
PY=~/Sources/WirelessNN/.venv/bin/python
$PY -m pytest nr_pusch_e316/tests            # синтетика: многолучёвость, CFO до ±41 кГц, 2 антенны
$PY -m nr_pusch_e316.selftest                # плата: цифровой loopback AD9361, без излучения
$PY -m nr_pusch_e316.rx_pusch --sim --snr 15 --cfo 4000
$PY -m nr_pusch_e316.tx_pusch --freq 3.5e9 --atten 30 --seconds 120   # TX1, циклически
$PY -m nr_pusch_e316.rx_pusch --freq 3.5e9 --gain auto --captures 4    # RX1, 7 кадров на захват
$PY -m nr_pusch_e316.rx_pusch --file cap.npy --rx-ant 2               # офлайн
```

`--mod/--prb/--seed` у TX и RX должны совпадать: приёмник сам воспроизводит
транспортный блок по seed и считает BER/BLER, а также EVM по известным данным.
`--rx-ant 2` принимает RX1+RX2 (2R2T), оценка канала и LMMSE — по обеим антеннам.

## Как устроен приёмник (`receiver.py`, `sync.py`)

1. **Поиск кадра** — корреляция захвата с временны́м DMRS-символом (4 частичные
   корреляции по 256 отсчётов, сумма модулей — устойчиво к CFO до ±60 кГц),
   нормировка на локальную энергию.
2. **Снятие ±512-неоднозначности** (DMRS Type-1 — гребёнка 2, символ периодичен) и
   **дробный CFO** — CP-метрика по всем 14 символам слота.
3. **Целый CFO** (кратный 30 кГц) — из набега фазы между частичными корреляциями.
4. **Шум** — мощность в паузе после слота; **SNR** — ⟨|ĥ|²⟩/N0.
5. OFDM-демодуляция Sionna (`OFDMDemodulator`, окно сдвинуто в CP на `--ta` отсчётов,
   линейная фаза компенсируется через `l_min`).
6. WirelessNN: оценка канала по DMRS → LMMSE → демаппер → LDPC → биты.

## Железо (`sdr.py`)

libiio 0.26 (Homebrew, arm64) через чистые python-биндинги `iio.py`
(`$PYLIBIIO_PY` или `~/.local/lib/python3*/site-packages/iio.py`). Особенности E316:
после перестройки первые ~4 буфера RX устаревшие (libiio держит 4 блока) — `capture()`
их сбрасывает; LO может быть в `powerdown` после SoapySDR — снимается; буфер нужно
уничтожать до контекста. Для `fs=30.72 MSps` в режиме 2R2T это верхний предел AD9361.
По USB (NCM, 100 Мбит) поток непрерывно не идёт — приём пакетный, по буферам
(2¹⁷ отсчётов = 7 кадров за захват).

## Результаты

* Синтетика (`tests/`): QPSK 68 PRB, 4-лучевой канал, CFO 0 / 3 кГц / −41 кГц при
  25 / 20 / 15 дБ — 0 битовых ошибок, тайминг точный, оценка CFO в пределах 300 Гц.
* Плата, цифровой loopback (2026-10-14): 7 слотов в захвате, 0 ошибок, EVM −52 дБ,
  период кадра ровно 18048 отсчётов.
* Эфирный тест TX1→RX1 требует запуска `tx_pusch` (см. выше).
